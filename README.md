# 📜 AI Poetry Translator

Проект по дисциплине "Машинное обучение и обработка данных" — сервис, позволяющий переводить стихотворения с использованием больших языковых моделей.

В рамках проекта была реализована система художественного перевода стихотворений с русского языка на основе языковой модели Qwen2.5-1.5B-Istruct. Основной акцент проекта сделан на применении методов prompt engineering для сохранения смысла, ритма и художественной выразительности оригинального текста. Модель была загружена и развернута локально на сервере, после чего интегрирована в веб-приложение для удобного взаимодействия с пользователем.

**Цель проекта:**  
Цель проекта — разработать интеллектуальный сервис для автоматического перевода стихотворений с русского языка на язык по выбору с помощью языковой модели, обеспечивающий сохранение художественного стиля, эмоциональной окраски и структуры оригинального текста.

**Протестировать реализованный сервис можно по [ссылке](http://5.159.102.10:8501/).**

## Описание проекта

Сервис принимает стихотворение на русском языке и генерирует его литературный перевод на выбранный язык с использованием LLM-модели.

Для повышения качества перевода применялись методы prompt engineering. Для модели формировался специальный prompt, содержащий набор инструкций, направленных на:
- сохранение структуры оригинальных строк,
- поддержание поэтического ритма и стиля,
- сохранение образности и символизма произведения,
- использование художественного, а не буквального перевода,
- исключение пояснений и сокращений текста,
- сохранение всех частей оригинального стихотворения и структуры переносов строк.
Такой подход позволил получать более точные и литературно выразительные переводы поэтических произведений.

Модель Qwen2.5-1.5B-Instruct была загружена и развернута локально на сервере, что позволило обеспечить автономную работу сервиса без обращения к внешним API.

## Архитектура системы

В основе проекта лежит языковая модель **Qwen2.5-1.5B-Instruct**, предназначенная для генерации текста на естественном языке.

Пользователь вводит стихотворение через веб-интерфейс, после чего текст передается на backend-сервер. Далее система формирует специальный prompt, содержащий:
- исходное стихотворение;
- инструкции по сохранению художественного стиля;
- требования к ритму и смыслу;
- параметры генерации.

Сформированный запрос передается в локально развернутую модель Qwen2.5-1.5B-Instruct, которая генерирует литературный перевод произведения.

Полученный результат отображается пользователю через веб-приложение.

Использование prompt engineering позволило существенно повысить качество художественного перевода и сохранить особенности оригинальной поэзии.
